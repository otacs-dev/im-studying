* Tensão elétrica (com/sem corrente) --> forma o Bit (0 ou 1)
* 8 Bits agrupados --> formam o Byte
* Byte + Convenção de interpretação (tabela ASCII, tipo de dado, etc.) --> formam o Dado/Instrução
* Instruções binárias organizadas --> formam a Linguagem de Máquina

* Linguagem de Máquina + Compilador/Interpretador (traduz código de alto nível) --> permitem a existência da Variável (endereço de memória + valor gravado)

* Variáveis (guardam dados) + Lógica (instruções/algoritmos) --> formam o interior das Funções
* Funções + Variáveis relacionadas --> formam Classes (que dão origem aos Objetos, ao serem instanciadas)
* Classes + Funções soltas --> formam Módulos(Arquivos de código)
* Módulos relacionados --> formam Bibliotecas (Libraries)
* Bibliotecas + Arquitetura base (Architectural Pattern/regras) --> formam Frameworks

        E tudo isso obedece às regras sintáticas e semânticas de uma Linguagem de Programação
